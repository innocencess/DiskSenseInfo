# DiskSenseInfo 0.1.4

- DiskPulse 改名為 DiskSenseInfo：App 顯示名稱、視窗、通知標題、匯出報告、選單列 DSI、Xcode 專案、可執行檔及 DMG 名稱同步更新。
- 新圖示採用選定 C 款：淺薰衣草色玻璃底、深靛藍磁碟及小紫色狀態點。App 側邊欄也使用新圖示。
- 沿用 app.diskpulse.monitor 與舊資料目錄 ~/Library/Application Support/DiskPulse/，不搬移或刪除設定／歷史。舊版與新版不可同時執行；安裝時退出並移除旧 App，保留資料目錄。
- 保留 USB 速度與 SMART 原因說明等既有功能，版本更新為 0.1.4。
- 仍採 ad-hoc 簽署，尚未完成 Apple 公證。
